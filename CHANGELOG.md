# Changelog

This changelog mirrors the in-app "What's New" panel shipped with the current
client.

## [1.5.0] - 2026-03-04

- Desktop app for Windows
- Export and import projects as `.rcui` files for backup or sharing
- Favorite projects to find them quickly in the sidebar
- Mobile-friendly editor support for phones and tablets
- Offline support with automatic sync after reconnect
- Dashboard improvements for mobile devices
- In-app "What's New" panel

## [1.4.0] - 2026-01-13

- Rename projects directly from the top-left panel in the editor
- Rename elements inline from the hierarchy panel
- Tutorial overlay for first-time users
- Shortcuts panel for keyboard references
- Faster page loads and smoother editor performance
- Refreshed glass-morphism UI across the app

## [1.3.0] - 2025-12-01

- Share projects publicly or privately
- Invite collaborators with view, comment, or edit access
- Leave comments directly on projects
- Real-time notifications for shares, comments, and updates
- Live updates when collaborators edit shared projects

## [1.2.0] - 2025-10-15

- Support tickets from the dashboard
- Ticket status and message history
- User discovery/profile viewing
- Better account security and protection

## [1.1.0] - 2025-09-01

- Asset manager for images and backgrounds
- Snippet library for reusable UI components
- Version history with snapshot restore/delete
- Plans and billing for Free, Solo, and Team tiers
- Community templates
- Teams with role-based access
- Draft project improvements
- Dashboard project duplication

## [1.0.2] - 2025-07-15

- Context menus for elements and hierarchy items
- Drag-and-drop reordering in the hierarchy panel
- Multi-select with Ctrl/Shift click
- Parent/child selection shortcuts
- Copy and paste for elements
- Snap-to-grid and alignment guides
- Cursor-aware zoom improvements
- Layer ordering controls

## [1.0.1] - 2025-06-15

- Shadow, outline, and blur effects
- Undo and redo support
- Auto-save indicator improvements
- Smoother canvas panning and resizing
- Fix for element anchors on resize

## [1.0.0] - 2025-06-01

- Visual drag-and-drop editor for Rust CUI interfaces
- Panels, buttons, text, images, input fields, countdowns, and scroll views
- Property inspector for anchors, offsets, colors, fonts, and shadows
- Element hierarchy panel with nesting, visibility, and locking
- Color picker with hex/RGB input and recent colors
- Code generation for Rust CUI output
- Auto-save
- Project dashboard with search, create, rename, and trash
- Keyboard shortcuts for duplicate, delete, multi-select, and more
- Dark IDE-style workspace
- Email and magic-link authentication
